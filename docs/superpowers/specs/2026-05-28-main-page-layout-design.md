# 主功能页布局改造设计

## 目标

以现有 B 站弹幕数据可视化页面为基础，按确认后的双版本布局重组主功能页。V7 作为普通用户基础版，AI 增强态作为配置 API 后的版本。页面需要更接近完整产品界面，同时保留当前已有的数据展示、BV 搜索、筛选、自定义榜单等能力。

## 页面结构

页面顶部为独立标题导航区，不参与功能模块布局。左侧展示项目标题和英文副标题，右侧放置“登入”按钮和“菜单”按钮，为后续登录页、侧边菜单或更多功能入口预留位置。

排行模块位于标题导航下方，是主页面的第一块核心内容。该模块分为三层：

1. 顶部快捷按钮行：包含“搜索”和“对比”两个按钮，用于快速跳转到搜索筛选区和视频对比区。
2. 榜单控制行：左侧为“热门榜单 / 自定义榜单”按钮切换，右侧为排序方式选择。
3. 排行可视化区：展示排行视频标题及可视化数据对比。

排行可视化区下方、视频数据区域上方放置操作按钮。左侧为“搜索及历史查看”，右侧依次为“添加到对比中”和“添加到自定义榜单”。

## 排序方式

排序选择默认使用官方排序。可选项包括：

- 官方排序
- 点赞数排序
- 收藏数排序
- 弹幕数排序
- 硬币数排序

排序作用于当前榜单视图。热门榜单和自定义榜单均复用同一排序控件。

## 当前视频信息区

排行模块下方展示当前选中视频的信息，分为三列：

- 视频封面和标题
- 当前视频数据：播放、点赞、收藏、弹幕、硬币
- 分布分析：视频内时间分布、弹幕长度分布

该区域根据排行点击、视频筛选或搜索结果更新。

## 搜索筛选区

搜索筛选区继续承载现有 BV 搜索、历史搜索、弹幕内容筛选、user_hash 筛选、导入导出和结果表格。顶部“搜索”按钮和“搜索及历史查看”按钮均可定位到该区域。

## 视频对比区

页面底部新增视频对比区。用户可通过“添加到对比中”将当前视频加入对比位。对比区采用左右对半布局，显示 A/B 两个视频的数据：

- 封面
- 标题
- 移出对比按钮
- 播放数
- 点赞数
- 收藏数
- 弹幕数
- 硬币数

基础指标采用纵向分段展示。每个指标先显示左右对半的 A/B 数值，再紧跟该指标的整行对比图表：

- 播放数 A/B 数值，播放图表
- 点赞数 A/B 数值，点赞图表
- 收藏数 A/B 数值，收藏图表
- 弹幕数 A/B 数值，弹幕数图表
- 硬币数 A/B 数值，硬币图表

基础指标之后展示弹幕分析对比：

- 弹幕时间分布
- 关键词差异

## API 用户增强态

普通用户默认使用 V7 基础版，不显示 AI 评价相关入口。

当用户配置并启用 API 后，页面进入 AI 增强态。增强态必须严格复用 V7 的普通用户页面布局，不得重排、删减或简化基础模块，只增加以下内容：

- 在 V7 版“搜索及历史查看”右侧按钮栏的最左侧增加“AI评价”按钮。
- 在“词云 · user_hash · 弹幕查询筛选 · 结果表格”下方增加 AI 评价文字内容模块。
- 在视频对比区标题栏最右侧增加“AI评价”按钮。
- 在视频对比区底部增加 AI 评价文字内容模块。

AI 评论内容用于展示对当前视频或 A/B 对比视频的文字总结，包括数据表现、弹幕热度、互动指标、关键词差异和整体评价。

## 视觉方向

采用深色科技仪表盘风格，延续开始页和现有主页面的蓝紫暗色、玻璃拟态、渐变高亮风格。模块之间使用清晰卡片边界和层级间距，重点突出排行可视化和视频对比。

## 实现范围

本次改造主要涉及：

- `web/index.html` 的页面结构重排
- `web/css/dashboard.css` 的布局和视觉样式调整
- `web/js/app.js` 的排序、锚点跳转、对比列表和新增按钮交互

不改变现有后端采集接口，不改变 `web/data/*.json` 的基础读取方式。若收藏数或硬币数字段在某些数据源中缺失，前端显示为 0 或空状态。
