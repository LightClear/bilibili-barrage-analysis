## 项目一句话介绍

本项目是一个本地运行的 B 站弹幕数据采集与可视化分析系统，支持热门榜单归档、BV 视频实时搜索、弹幕图表分析、视频对比、账号权限、AI 评价和本地储存清理。

## PPT 核心表达

- 数据从 B 站视频和弹幕接口采集，经过解析、清洗、统计后进入可视化工作台。
- 热门榜单采用按日期归档、按视频拆分弹幕 JSON 的方式，解决了切换榜单时全量弹幕加载导致的卡顿问题。
- BV 搜索和热门榜单刷新采用后台任务，前端轮询任务进度，避免长任务阻塞页面。
- 账号系统提供普通用户、管理员、owner 的权限边界，并支持个人屏蔽词、API 开关和账号级模型 Provider。
- AI 分析采用本地统计摘要加模型评价的方式，并有缓存、重新分析、失败回退和使用统计。
- 本地文件模式配合自动清理和管理员手动清理，适合课程项目展示，也为后续 MySQL 化预留了结构。

## 演示路线

1. 启动服务并进入 `start.html`。
2. 登录演示账号，进入主功能页。
3. 展示热门榜单、日期切换和榜单滚动。
4. 点击一个视频，展示按需加载弹幕后的时间分布、长度分布、词云和用户贡献榜。
5. 搜索一个 BV 号，展示后台任务进度和弹幕采集诊断。
6. 加入两个视频做对比，展示对比图表和 AI 评价。
7. 进入账号中心，展示个人屏蔽词、API Provider 和管理员储存清理。

## 当前完成状态

截至当前整理，项目已完成可运行的本地文件模式主流程。核心功能包括热门榜单、日期归档、按需弹幕加载、BV 搜索任务、可视化图表、视频对比、账号权限、AI 分析、储存清理和测试覆盖。MySQL 相关表结构和迁移工具已经准备，但主业务流程仍默认使用文件和内存任务表。
