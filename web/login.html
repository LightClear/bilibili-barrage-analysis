账号规则

  • 账号支持字母、数字、下划线，可为纯数字。
  • 密码需要 8-32 位，并同时包含字母和数字。
  • 邮箱验证码和 AI 验证码为本地 DEMO，用于模拟防攻击流程。
  • 真实部署时应替换为数据库、邮件服务和服务端会话。

个人资料

API 接入

这里控制当前账号是否启用 AI/API 功能。开启开关后仍需保存本账号自己的模型 API 配置，主页面才会显示并允许使用 AI 评价。

自带模型 API

用于接入 DeepSeek、OpenAI 或其他 OpenAI-compatible 服务。真实 Key 只保存在后端本机加密存储中，页面仅显示脱敏结果。

B站历史弹幕补抓

用于“历史补抓”。凭证只保存在后端本机加密存储中，不写入前端文件，也不会在页面回显完整内容。SESSDATA 等同登录凭证，请勿截图或提交到仓库。

AI 使用统计

这里只统计本项目内的 AI 分析请求、缓存命中和外部模型调用次数，不读取第三方 API 余额或账单。

屏蔽词设置

每行一个屏蔽词，最多 200 个。当前模式为整条删除，保存后在重新获取弹幕或管理员更新热门榜单时生效。

管理员界面

演示身份切换

只影响主功能页的演示权限，不改变当前账号的管理员权限。

热门榜单更新

按默认 50 个视频更新当前热门榜单，并写入当天归档。

等待更新 0%

点击更新后会显示采集步骤。

全局屏蔽词

全局词库会叠加到所有账号的个人屏蔽词上，适合放通用广告、刷屏和明显无意义表达。

AI 缓存

缓存命中时不会再次调用外部模型，可减少用户 API 开支；清理只会影响缓存，不会删除最新报告文件。

本地储存清理

用于控制本地文件模式下的磁盘占用。默认只清理旧前端大文件、孤儿弹幕分库和过期 AI 缓存；历史归档需要单独输入保留天数并确认。

AI 调用统计

统计本项目观察到的调用、缓存和失败回退；真实余额和扣费以模型平台控制台为准。
